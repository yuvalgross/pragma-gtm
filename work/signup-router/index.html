Signup router: who gets a human this week, and what that human does first.

A small Python tool that takes a week of product trial signups, drops anyone who is already a customer or partner, scores the rest from 0 to 100 on usage, company fit, integration path and pain signals, and assigns one next action per account. Every row carries the evidence behind its score.

How it works

InputWeekly signup export with usage volume per week, products used and integration path, plus the columns Clay would add: company, size, funding and pain signals. In Clay the week is a saved segment in Audiences, read with the Clay CLI.
GateExisting customers, partners and personal email domains are dropped before any scoring and logged with the reason.
ScoreUsage 35, company 25, integration 25, pain 15. Accounts that arrive through a marketplace or a reseller score a quarter on integration, because a partner already sells to them.
RouteAbove 70 and rising (three weekly steps up, week four at least 1.3 times week one): custom benchmark and an enterprise conversation. 45 to 70: mid tier offer and a shared Slack channel. Below 45, or usage falling or never started: nurture. Partner accounts go to the partner owner.

Who gets a person, and who doesn't

The question every inbound flow has to answer first. Here the rules are set by hand and run in order, top to bottom. No AI makes the call, and every row carries the evidence behind its score, so a person can check it.

The gate is a rule, never a weight, so no change to the scoring can send an existing customer a sales task. In this run nurture is a label on the row; the automated nurture track that would follow it is designed, not running.

Synthetic input. Every work domain ends in .example; personal email rows use public webmail domains so the gate has something to drop. 17 accounts are built by hand to exercise every rule, the rest are generated with a fixed seed. Company names, volumes and signals are invented and say nothing about real companies. The column names are my assumption of what a product database and a Clay table would hold.

What I would change first

Two results from this run need a conversation before the weights are trusted. A 900 person company scores 69 and gets a mid tier offer, because integration and usage outrun a weak company fit. That is the first weight I would revisit. And two accounts hit 100, so the scale saturates at the top. A tie break on last week's volume is the simplest fix. The long tail adds a third: a 4 person team with flat test volume reaches 48 and a mid tier offer, mostly on the integration path. A floor on last week's volume before any person is assigned would stop that.

How I would judge the tool: flagged accounts should convert to a paid tier within 90 days at a higher rate than unflagged accounts of the same age. If they do not after two weekly cycles, change the weights or drop it. The weekly check is simpler still: does the account owner agree with the top five.

Where Clay Audiences and the CLI fit

In this run the Clay columns are typed in. In a real workspace the week's signups sit in Clay Audiences, which holds a company's own people, companies and deals, and the Clay CLI reads them from a terminal or from Claude Code. Reading and counting cost no credits; only enrichment does. The commands below come from Clay's documentation. I have not run them against a workspace.

# 1. Count the week's signups (a saved segment, free)
clay audiences records search-count --audience-id SIGNUPS_WEEK_ID

# 2. Pull the rows the router scores
clay audiences records search-ids --audience-id SIGNUPS_WEEK_ID --limit 100
clay audiences records get --entity-type people --ids 101,102,103

# 3. Two fields to hold the result on each company
clay audiences fields create --entity-type companies --name "Router score" --data-type number
clay audiences fields create --entity-type companies --name "Next action" --data-type text

# 4. One live segment per next action
clay audiences create --entity-type companies --name "Custom benchmark" --filter ./custom_benchmark.json

Three limits from the same docs shape the design. The CLI reads records but cannot write values into them, so the scores go back through Clay's upsert-audiences-record workflow action. A segment is a saved filter, so Custom benchmark stays current as scores change, but segments cover people and companies only; deals arrive through a CRM sync and are read only. And most commands allow 60 calls a minute, so the router asks for the week, not the whole workspace.

"""
Signup router: decides which product trial signups get a human this week
and what that human does first.

    python3 signup_router.py data/signups_week_43_synthetic.csv --out output/

Pipeline
  1. Gate (hard, before any scoring): drop existing customers and partners, and
     personal email domains. Log the reason.
  2. Score 0 to 100: usage 35, company 25, integration 25, pain signals 15.
  3. One next action per account from score and trend.
  4. Write scored.csv, excluded.csv, top5.md and a summary.

Exclusions are a gate, never a weight: no tuning can send a customer a sales
task. Weights and rules are set by hand at the top of this file.
"""
import argparse
import csv
import json
import os
from datetime import date

# ---- rules set by hand ------------------------------------------------------

# In production this list comes from a CRM export of customers, partners and
# open deals. Here it holds the two synthetic domains the test rows use.
EXCLUDED_DOMAINS = {"customer-one.example", "partner-two.example"}
PERSONAL_DOMAINS = {
    "gmail.com", "googlemail.com", "outlook.com", "hotmail.com", "yahoo.com",
    "icloud.com", "proton.me", "protonmail.com", "gmx.de", "gmx.net", "web.de",
}

WEIGHTS = {"usage": 35, "company": 25, "integration": 25, "pain": 15}

# Direct opportunity by integration path. Accounts that arrive through a
# marketplace or a reseller already have a partner selling to them, so they
# score a quarter of a direct deal and go to the partner owner instead.
INTEGRATION_POINTS = {
    "direct_api": 25, "open_framework": 25, "self_hosted": 25,
    "partner_marketplace": 6, "reseller_channel": 6, "unknown": 10,
}
TARGET_CATEGORIES = {"core_segment"}

THRESHOLD_ENTERPRISE = 70
THRESHOLD_MIDTIER = 45

# ---- scoring ----------------------------------------------------------------


def volume(row):
    return [int(row[f"volume_w{i}"] or 0) for i in range(1, 5)]


def trend(vols):
    """'none' if no usage at all; 'rising' if three of three week over week steps are up and w4 >= 1.3 x w1."""
    if not any(vols):
        return "none"
    steps = [b > a for a, b in zip(vols, vols[1:])]
    if all(steps) and vols[0] and vols[3] >= 1.3 * vols[0]:
        return "rising"
    if vols[3] < 0.8 * vols[0]:
        return "falling"
    return "flat"


def score_usage(row):
    vols = volume(row)
    t = trend(vols)
    pts, why = 0, []
    if t == "rising":
        pts += 15
        why.append("volume up four weeks running")
    elif t == "flat":
        pts += 6
    level = vols[-1]
    if level >= 25000:
        pts += 10
        why.append(f"{level:,} units last week")
    elif level >= 8000:
        pts += 7
        why.append(f"{level:,} units last week")
    elif level >= 2000:
        pts += 3
    products = set(row["products_used"].split(";")) if row["products_used"] else set()
    if {"addon_x", "addon_y", "addon_z"} & products and {"core_a", "core_b"} & products:
        pts += 10
        why.append("add on used alongside core product")
    return min(pts, WEIGHTS["usage"]), why, t


def score_company(row):
    pts, why = 0, []
    if row["category"] in TARGET_CATEGORIES:
        pts += 10
        why.append(row["category"].replace("_", " "))
    hc = int(row["headcount"] or 0)
    if 20 <= hc <= 500:
        pts += 8
        why.append(f"{hc} staff")
    elif hc > 500:
        pts += 4
    try:
        fund = int(row["last_funding_months_ago"])
    except ValueError:
        fund = 99
    if fund <= 18:
        pts += 7
        why.append(f"funded {fund} months ago")
    return min(pts, WEIGHTS["company"]), why


def score_integration(row):
    path = row["integration_path"] or "unknown"
    pts = INTEGRATION_POINTS.get(path, INTEGRATION_POINTS["unknown"])
    why = [path.replace("_", " ")]
    if path in ("partner_marketplace", "reseller_channel"):
        why.append("scores a quarter, a partner already sells to this account")
    if row["hosting"] == "self":
        why.append("self hosted")
    return pts, why


def score_pain(row):
    signals = [s for s in row["pain_signals"].split(";") if s]
    pts = min(5 * len(signals), 15)
    why = [s.replace(":", ": ") for s in signals]
    if row["existing_tool"] == "incumbent":
        pts = min(pts + 5, 15)
        why.append("incumbent tool already in product (displacement, warm)")
    elif row["existing_tool"] == "inhouse":
        pts = min(pts + 3, 15)
        why.append("in house build")
    return pts, why


def next_action(total, t, path):
    if path == "partner_marketplace":
        return "Nurture, flag to the marketplace partner owner"
    if path == "reseller_channel":
        return "Nurture, flag to the reseller channel owner"
    if t in ("falling", "none"):
        # a trial that stopped or never started gets no person, whatever the fit
        return "Nurture"
    if total > THRESHOLD_ENTERPRISE and t == "rising":
        return "Custom benchmark, open the enterprise conversation"
    if total >= THRESHOLD_MIDTIER:
        return "Offer the mid tier, open a shared Slack channel"
    return "Nurture"


def gate(row):
    domain = (row["domain"] or "").lower().strip()
    if not domain:
        return "no domain"
    if domain in EXCLUDED_DOMAINS:
        return "existing customer or partner"
    if row["email_type"] == "personal" or domain in PERSONAL_DOMAINS:
        return "personal email"
    return None


def route(rows):
    scored, excluded = [], []
    for row in rows:
        reason = gate(row)
        if reason:
            excluded.append({"account_id": row["account_id"], "domain": row["domain"], "reason": reason})
            continue
        u, u_why, t = score_usage(row)
        c, c_why = score_company(row)
        s, s_why = score_integration(row)
        p, p_why = score_pain(row)
        total = u + c + s + p
        scored.append({
            "account_id": row["account_id"],
            "company_name": row["company_name"],
            "domain": row["domain"],
            "hq_city": row["hq_city"],
            "country": row["country"],
            "headcount": row["headcount"],
            "integration_path": row["integration_path"],
            "trend": t,
            "usage": u, "company": c, "integration": s, "pain": p,
            "score": total,
            "next_action": next_action(total, t, row["integration_path"]),
            "why": "; ".join(u_why + c_why + s_why + p_why),
        })
    scored.sort(key=lambda r: (-r["score"], r["company_name"]))
    for i, r in enumerate(scored, start=1):
        r["rank"] = i
    return scored, excluded


def write_outputs(scored, excluded, out_dir, source):
    os.makedirs(out_dir, exist_ok=True)
    with open(os.path.join(out_dir, "scored.csv"), "w", newline="") as f:
        cols = ["rank", "account_id", "company_name", "domain", "hq_city", "country", "headcount",
                "integration_path", "trend", "usage", "company", "integration", "pain", "score", "next_action", "why"]
        w = csv.DictWriter(f, fieldnames=cols)
        w.writeheader()
        w.writerows(scored)
    with open(os.path.join(out_dir, "excluded.csv"), "w", newline="") as f:
        w = csv.DictWriter(f, fieldnames=["account_id", "domain", "reason"])
        w.writeheader()
        w.writerows(excluded)
    top = scored[:5]
    lines = [
        f"# Signup router, run {date.today().isoformat()}",
        f"Input: {source} ({len(scored) + len(excluded)} rows). Gate dropped {len(excluded)}. Scored {len(scored)}.",
        "",
        "| # | Account | Score | Why | Next action |",
        "| --- | --- | --- | --- | --- |",
    ]
    for r in top:
        acct = f"{r['company_name']}, {r['hq_city']}, {r['headcount']} staff, {r['integration_path'].replace('_', ' ')}"
        lines.append(f"| {r['rank']} | {acct} | {r['score']} | {r['why']} | {r['next_action']} |")
    lines.append("")
    reasons = {}
    for e in excluded:
        reasons[e["reason"]] = reasons.get(e["reason"], 0) + 1
    lines.append("Dropped before scoring: " + "; ".join(f"{n} {r}" for r, n in sorted(reasons.items())))
    with open(os.path.join(out_dir, "top5.md"), "w") as f:
        f.write("\n".join(lines) + "\n")
    summary = {
        "run_date": date.today().isoformat(),
        "input": source,
        "rows_in": len(scored) + len(excluded),
        "excluded": len(excluded),
        "excluded_by_reason": {r: sum(1 for e in excluded if e["reason"] == r) for r in sorted({e["reason"] for e in excluded})},
        "scored": len(scored),
        "weights": WEIGHTS,
        "thresholds": {"enterprise": THRESHOLD_ENTERPRISE, "mid_tier": THRESHOLD_MIDTIER},
        "actions": {a: sum(1 for r in scored if r["next_action"] == a) for a in sorted({r["next_action"] for r in scored})},
    }
    with open(os.path.join(out_dir, "summary.json"), "w") as f:
        json.dump(summary, f, indent=2)
    print("\n".join(lines))


def main():
    ap = argparse.ArgumentParser()
    ap.add_argument("csv")
    ap.add_argument("--out", default="output")
    a = ap.parse_args()
    with open(a.csv, newline="") as f:
        rows = list(csv.DictReader(f))
    scored, excluded = route(rows)
    write_outputs(scored, excluded, a.out, os.path.basename(a.csv))


if __name__ == "__main__":
    main()
